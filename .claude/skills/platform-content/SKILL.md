# platform-content — algorithm-first content for IG / FB / Web

Every piece of content gets engineered for the platform's current ranking system.
Never write "generic social copy" — every choice (format, length, hook, CTA) must map to
a ranking signal, and you must be able to say which one.

## ⏰ FRESHNESS RULE (do this first, every time)

The snapshot below is dated. Before creating content:

1. **Check the snapshot date.** If it is **more than 30 days old**, or the user asks for
   "latest", refresh: run WebSearch for the target platform only —
   `"<platform> algorithm <current month year> ranking signals changes"` — and skim the
   top results for changes vs the snapshot.
2. **If anything changed:** apply the new knowledge to the content AND update the
   snapshot section + date in this SKILL.md (Edit tool) so the skill self-heals.
3. **If fresh (<30 days):** proceed directly — do not burn searches redundantly.

## 📸 ALGORITHM SNAPSHOT — updated 2026-07-19 (sources: Later, Hootsuite, Buffer, Sprout
Social, Social Media Examiner, SocialPilot, Google Search Central, Search Engine Journal)

### Instagram (2026)

- Separate ranking systems per surface (Feed / Reels / Stories / Explore).
- **Top 3 signals (per Adam Mosseri): watch time, sends-per-reach (DM shares), likes-per-reach.**
  DM shares are the #1 weighted signal for Reels — engineer "send this to someone" moments.
- **Saves > likes.** Checklists, data, templates, "save for later" utility content.
- **Watch completion** is the primary Reels metric — completion rate beats raw views.
  Reels up to 3 min are Explore-eligible, but only if retention holds.
- **Carousels have the highest engagement rate of any format** (~0.55% avg); each swipe
  counts as engagement and unfinished carousels get re-shown in Feed.
- **Originality:** original content gets 40–60% more distribution; 10+ reposts in 30 days
  → excluded from recommendations entirely.
- **SEO inside IG:** keywords in captions + profile now beat hashtags for discovery
  (hashtag follows are gone). Write captions with searchable keywords.
- Auto-translation of Reels captions/audio → international reach is free; don't hard-burn
  text into video that translation can't touch.
- First 2–3 seconds must carry: a question, unusual visual, or clear value statement.

### Facebook (2026)

- **Watch time is the strongest signal**; ≥50% retention at the video midpoint can ~4×
  reach — that's the threshold to engineer for.
- **Every uploaded video is a Reel** (since mid-2025); short-form is the distribution engine.
- **UTIS (since Jan 14, 2026):** ranking blends passive engagement with a daily in-feed
  user survey ("How well does this video match your interests?" 1–5). Optimizing for
  clickbait now backfires — content must genuinely match declared interests.
- **15–30s Reels get ~45% higher completion** than longer ones. Hook in first 3 seconds.
- **Photos get the highest Feed engagement; Reels get the highest reach** — choose by goal.
- Watermarked/recycled/low-edit videos get reach-limited (no TikTok watermarks, ever).
- **80/20 rule:** 80% value, 20% promotional. Fast comment/DM replies boost page ranking.

### Website (2026 — SEO / AEO / GEO)

- **AI Overviews** appear on ~5–15% of searches (informational/research heavy). Citations
  come almost entirely from top organic results → **rank organically first, then AI
  visibility follows.** Google's own guide: "AEO/GEO is still SEO."
- **No special AI files needed** — Google explicitly says llms.txt, AI-specific rewriting,
  chunking, or special schema are NOT required. Don't sell/implement those as magic.
- **E-E-A-T + entity recognition** are the differentiators: named authors with
  credentials, first-hand experience signals, consistent entity presence.
- **Topical authority via interconnected clusters** beats one-off posts: pillar page +
  cluster pages + internal links.
- Answer-first structure wins citations: give the direct answer in the first 1–2
  sentences under a question-matching H2, then expand.
- Human-reviewed AI-assisted content is fine; pure unedited AI-generated content at scale
  is a quality risk.

## 🏭 CREATION WORKFLOW

### 1. Intake
From the user's ask, establish: **platform(s) → goal (reach / engagement / saves /
conversion / SEO) → topic → brand voice** (check memory: SoftexEdge tokens, client canon).
Missing topic = ask once. Everything else: infer and state your picks.

### 2. Pick format BY GOAL (not by habit)
| Goal | Instagram | Facebook | Website |
|---|---|---|---|
| Max reach | Reel (completion-engineered) | Reel 15–30s | Pillar page targeting head term |
| Max engagement | Carousel (swipe-bait structure) | Photo + question post | Interactive/comment-driving blog |
| Saves/utility | Carousel checklist/template | Value post | How-to with answer-first blocks |
| Conversion | Reel hook → caption CTA → DM/link | 80/20 value post + CTA | Landing page (PAS/AIDA) |

### 3. Write with per-platform anatomy

**IG Reel:** Hook line (<3s, on-screen text + spoken) → 2–4 value beats with visual change
every ~2s → payoff that invites a SEND ("send this to your…") → caption: keyword-rich
first line, 2–4 sentence value, CTA, 3–5 niche hashtags max. Suggest audio + cover text.

**IG Carousel:** Slide 1 = scroll-stopping claim/hook; slides 2–8 = one idea per slide,
cliffhanger bottoms ("→"); last slide = save/share CTA. Caption same anatomy as Reel.

**FB post/Reel:** Native upload, no watermarks. Reel: 15–30s, hook <3s, midpoint retention
beat at 50%. Photo post: strong image + short conversational text ending in a genuine
question. Schedule reply window (first hour) into the plan.

**Website page:** Title + meta (≤60/≤155 chars, keyword front-loaded) → H1 → answer-first
intro (direct answer in 2 sentences) → H2s matching real query phrasings → E-E-A-T block
(author, credentials, first-hand evidence) → internal links to/from cluster → schema
(Article/FAQ/Product as applicable — standard schema, not AI-magic) → CTA.

### 4. Deliver
For each piece output: **(a)** the content itself, ready to paste/publish; **(b)** format
+ posting guidance (time, first-hour actions); **(c)** a 1-line algorithm rationale per
major choice ("carousel because saves-goal + highest engagement format").
Multi-platform asks: adapt the core idea per platform — never copy-paste the same copy.

### 5. Assets (optional, this project's stack)
Visuals → Magnific `images_generate` (check memory for brand tokens on brand work).
Video → `make-video` skill / remotion-video. Music → `suno-music`. Publishing to
Meta → the Meta Ads MCP is connected for paid; organic posting stays manual.

## Anti-patterns (never do)

- Same caption across platforms; hashtag walls (>5); engagement bait ("like if…") — UTIS
  punishes it; TikTok-watermarked video on FB/IG; burying the answer below 300 words of
  fluff on web; keyword-stuffed unreadable captions; promising "guaranteed viral".
